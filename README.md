# Offline-Hindi-Voice-Assistant
The Offline Hindi voice assistant is a privacy focused voice control system designed to run completely  without an internet connection. Built specifically for Raspberry Pi, the assistant uses local speech recognition to understand Hindi voice commands and respond using text to speech
Key Goals 
- Provide fully offline voice interaction
- Support hindi language commands
- Runs efficiently on Raspberry Pi hardware
- Maintain user privacy
- Offer a modular and extensible architecture
